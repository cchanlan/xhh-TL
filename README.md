# xhh-TL · 小火花模块中心

> Yunzai 插件：四游戏实时体力（原神 / 星铁 / 绝区零 / 鸣潮）、体力阈值推送、米游社签到与米游币、
> 原神与星铁的成绩汇总与配队、星铁抽卡记录、三游戏国服手动与自动兑换码。出图统一走毛玻璃模板。

体力模块基于 [xhh](https://github.com/YUYUYUYU2147/xhh/tree/v2) 改造，其余功能自建。


## 2.0：按需安装模块

新克隆只包含管理核心、帮助和更新入口，**不包含业务模块**。需要哪个功能，就安装哪个。

1. 安装核心并重启机器人。
2. 打开 **锅巴 → 扩展页面 → 小火花模块中心**。
3. 在“选择模块”中选择功能，点击 **安装**。公共依赖会一起下载。
4. 提示准备完成后，重启机器人。不会自动重启。
5. 重新打开模块管理查看安装状态；发送 `#小火花帮助` 查看可用指令。

卸载：选择已安装模块 → **卸载** → 确认 → 重启机器人。保留 CK、配置、订阅、抽卡记录和自定义素材；重新安装后继续使用。卸载过码部署模块不停止已有的独立过码服务。

更新：选择模块 → **更新** → 重启机器人，只更新所选模块及其依赖。`#小火花更新` 更新核心；核心和模块分别更新。

旧版锅巴看不到按钮时：选择模块 → “兼容操作”选择安装/卸载/更新 → 点击 **保存**。正常配置与所选模块操作会一同处理；完成后重新打开本页。

- “已关闭”不等于卸载：关闭保留代码，卸载会移除专属代码、素材与该版本下载缓存。
- 模块开关只作用于已安装功能，不会触发下载；启动时关闭的模块重新开启后需要重启。
- 绝区零角色立绘、鸣潮内置角色立绘、背景图库是可选资源包；未安装时使用可用的角色图片或默认背景。额外自备的鸣潮图库不上传、不删除。
- 空核心不需要 miao-plugin；依赖 miao 的功能安装后仍需自行安装 miao-plugin。业务模块沿用 Yunzai 宿主依赖，缺失时按日志所列依赖安装后重启。
- 模块源码：[xhh-TL-modules](https://github.com/cchanlan/xhh-TL-modules)。模块目录和下载包仅从官方仓库读取；本页不接受自定义代码 URL。
- 新安装命令使用浅克隆、单分支。旧仓库的 Git 历史不重写，完整克隆仍可能下载历史素材。

### 从旧版升级

先备份用户配置和数据、记录旧版提交号；不要清理 `data/`、`service/` 或自备图库。

推荐先按 [升级与恢复](docs/module-upgrade.md) 下载模块包，准备成功再切换核心。直接升级的旧安装在新核心首次启动时也会尝试迁移：沿用原功能开关、配置和订阅；迁移失败保留“待迁移”，在锅巴点击“迁移旧版功能”重试，再重启。断网且没有预下载包时，旧业务不会凭空继续运行，可恢复旧版后再迁移。

## 体力

```
#体力 / #tl                          原神 + 星铁 + 绝区零总览（鸣潮默认不含）
#原神体力 #星铁体力 #绝区零体力 #鸣潮体力    单查，支持 @他人
                                     别名 #ystl / #xttl / #zzztl / #mctl，*体力 = #星铁体力
#开启体力uid / #关闭体力uid              卡片是否显示 UID（一次管四个游戏）
#开启原神体力 / #关闭原神体力             控制总览是否含该游戏（四游戏各自独立）
#关闭原神123456789                     屏蔽单个号（四游戏各自独立，换游戏名即可）
#体力屏蔽列表
```

屏蔽与显示开关是两回事：`#关闭原神体力` 是把整个游戏从**总览**里摘掉；
`#关闭原神123456789` 是只屏蔽**那一个 UID**（不解绑、不影响体力推送）。
屏蔽时写 `#屏蔽星铁体力123456789` / `#隐藏鸣潮123456789` 也认，恢复用
`#开启星铁123456789` / `#恢复原神123456789`。

三种卡片样式（`tl_card_style`）：`classic` 经典多合一 / `portrait` 大立绘 / `widget` 桌面小组件。
大立绘与小组件随角色图片自动搭配渐变色；横版立绘占七成，保留原信息宽度，不再叠加底图。小组件自动裁去立绘外缘的透明、黑白留边并铺满顶部。无需另选配色。
小组件卡底部还能显示当前**限时活动**（活动名 + 进度 + 倒计时），条数由
`tl_widget_activity_limit` 控制，填 `0` 就不显示。
多账号合并出图，张数超 `tl_cards_per_msg` 自动转合并转发。数据取米游社实时便笺（优先 stoken）。
**绝区零体力只认 stoken**：米游社的 zzz 接口不接受普通 Cookie，只有 CK 的号查不了，
单查时会提示先【#扫码登录】，总览里该行静默跳过。
原神卡片额外带一行**参量质变仪**状态（今日可使用 / N天后可再次使用 / 尚未获得），数据来自
game_record 实时便笺接口，纯 stoken 凭证拉不到时该行自动隐藏。

**鸣潮**需要同机的 gsuid_core + 鸣潮插件（只读借它的 UID 绑定与登录凭证），并在锅巴打开
`waves_tl_enable`、用户自己发 `#开启鸣潮体力`；Windows 必须手填 `GsData.db` 路径。
可安装“鸣潮内置角色立绘”资源包，也可指向鸣潮插件已下载好的目录。

## 体力推送

群内每人各自设阈值，恢复到阈值以上时在该群 @你并发图。四游戏独立。

```
#原神体力推送 130       上限 200；星铁 300、绝区零 240、鸣潮 240
#原神体力全推送 130     监控名下所有 UID
#原神体力推送关闭
#体力推送列表
```

把「原神」换成**星铁 / 绝区零 / 鸣潮**即可设对应游戏，四游戏独立、互不影响；
「开启 / 打开」前缀可省，关闭词写前面（`#关闭原神体力推送`）或后面（`#原神体力推送关闭`）都认。

达标只 @ 一次，回落后自动重新武装；主号推送与全推送互斥；只能在群里设，默认 10 分钟一轮
（`resin_push_cron`）。

### 质变仪 / 洞天宝钱到期提醒

对**已开启原神体力推送**的人，在这两样东西「能用了」时于其订阅群 @ 提醒一次（配一张提醒卡）：

- **参量质变仪**：冷却结束、可再次使用时
- **洞天宝钱**：攒满（达到上限）时

数据复用你查询体力时的那份快照，**不额外请求米游社**；到点时刻会落盘，云崽重启后自动恢复定时。
需要你至少查询过一次体力才会有数据（`resin_timer_enable`，默认开）。

## 三游戏国服兑换码

先发送 `#扫码登录` 绑定账号。原来的 `#兑换码` / `*兑换码` / `%兑换码` 查码指令不变。

| 操作 | 原神 | 星铁 | 绝区零 |
| --- | --- | --- | --- |
| 一键使用近期收录码 | `#使用兑换码` | `*使用兑换码` | `%使用兑换码` |
| 使用指定码 | `#使用兑换码 兑换码` | `*使用兑换码 兑换码` | `%使用兑换码 兑换码` |
| 手动别名（同样可带码） | `#兑换码使用` | `*兑换码使用` | `%兑换码使用` |
| 开启自动兑换 | `#自动兑换码` / `#自动兑换码开启` | `*自动兑换码` / `*自动兑换码开启` | `%自动兑换码` / `%自动兑换码开启` |
| 关闭自动兑换 | `#自动兑换码关闭` | `*自动兑换码关闭` | `%自动兑换码关闭` |
| 查看自动状态 | `#自动兑换码状态` | `*自动兑换码状态` | `%自动兑换码状态` |

- 三种前缀后均可显式加 `原神` / `星铁` / `绝区零`，游戏名优先，例如 `#星铁使用兑换码`、`#绝区零自动兑换码开启`；`兑换码使用` 别名同理。前缀不可省略。
- 指定多个码用空格、逗号或分号分隔，最多20个。只操作发指令者的全部已绑定国服角色，不能 @他人代兑；海外服继续使用原插件功能。
- 自动兑换按用户、机器人、游戏分别订阅，默认未开启；每10分钟检查，群里开启在该群回报，私聊开启在私聊回报。重复开启会更新回报位置。关闭后停止后续兑换，已发出的请求不能撤回。
- 自动兑换仅使用米游社官方前瞻直播源，社区码、其他活动码及永久通用码不进入自动队列；官方源无新码或请求失败时不会回退社区源。已有订阅继续有效。
- 手动使用兑换码不带码时合并米游社官方前瞻源与社区 `https://db.hashblen.com/codes`，仅处理最近7天收录的码；收录时间不等于有效期，也不保证适用于国服，最终以兑换接口返回为准。通用码 `GENSHINGIFT` / `STARRAILGIFT` / `ZENLESSGIFT` 不纳入一键及自动兑换，仍可手动指定。
- 成功、已用、无效、过期按游戏和角色去重7天；自动失败最多尝试3轮，手动指定码可再次尝试。账号间串行、同一角色两次兑换间隔至少6.5秒，遇到冷却或安全验证停止本轮。
- 订阅存在 Redis `Yunzai:ycdk:auto:subs`，兑换结果存在 `Yunzai:ycdk:auto:seen:*`；不保存 Cookie。不将账号凭证发送给社区码源，Cookie 只发送米哈游官方域名。
- 兑换客户端使用 Node 基础 API（整个模块版要求 Node 18.17+），兼容 node-fetch v2/v3；真机仅在 Linux / JiuLi 验证，Windows / Miao-Yunzai / TRSS-Yunzai 未实跑。

## 米游社签到 / 米游币

两回事：签到领原石走游戏 UID + cookie_token；米游币是在社区做任务，走米游社账号 + **stoken**。
米游币规则已变：各版块共享进度，任一版块签到即拿满当日奖励，浏览 / 点赞 / 分享不再计入。

```
#原神签到 / #星铁签到 / #绝区零签到     立即签，多账号逐个签
#原神自动签到 / #原神自动签到关闭       订阅每日自动签
#yuanshen签到 / #ys签到                原神签到别名
#yuanshen自动签到 / #ys自动签到        原神自动签到别名
#签到列表 / #签到状态 / #签到查询
#自动签到列表 / #自动签到状态 / #自动签到查询

#米游币签到  #米游币余额
#开启自动米游币 / #关闭自动米游币  #自动米游币列表
```

签到和自动签到均支持游戏别名：原神 / yuanshen / ys，星铁 / 崩铁 / 星穹铁道 / xt，绝区零 / zzz。
自动签到可不加后缀或加「开启 / 开 / 打开」启用，加「关闭 / 关 / 取消 / 停止」停用；例如 `#ys自动签到关闭`、`#yuanshen自动签到开启`。

签到用稳定 `device_id` + 真设备指纹，撞码概率低。米游币任一版块签到即拿满当日奖励。

米游社的奖励是**延迟入账**的，签到成功后余额要过一会儿才更新，所以收益一律按米游社给的
「今日已获得」统计；偶尔赶在入账前出图，会写一句「收益稍后到账」，不用重跑任务。

**撞码自动处理**：本插件（含 genshin、miao-plugin 等走米游社的指令）一撞验证码，就会**自动过码
并重试原请求** —— 你看到的直接是正常结果，不用做任何事、也不会收到打扰。

自动过码**开箱即用**：默认走插件自带的公共过码服务 `https://geetest.lyln114514.com/solve`，
不用部署、不用配置。公共服务连不上时只提示「稍后再试」，不影响其它功能。

想把过码放在自己机器上（不依赖公共服务），**一键装好**：

```
#过码部署          拉服务、装依赖、起进程、写配置，一步到位；服务有新版本时也发这条
#过码服务状态       看服务在不在、文件全不全、配置有没有生效
```

装好后配置会自动指向本机 `http://127.0.0.1:8766/solve`。想切回公共服务或换别的远程服务，
把配置 `auto_verify_addr` 填成对应地址（公共：`https://geetest.lyln114514.com/solve`；
别人部署的：`http://服务器IP:8766/solve`）即可；手动装法见仓库 **`solver` 分支**的
`service/geetest/README.md`。

## 原神

```
#全部深渊              深境螺旋 + 幽境危战 + 小剧诗关键关，三列合一（原神专属，星铁见下）
#小剧诗 / #小幻想       幻想真境剧诗关键关（加「上期」看上期）
#幻想角色 / #幻想剧诗   当期限制元素与可用角色；#下期幻想角色、#幻想202607
#深渊配队 / #危战配队   高频满星队，绑 CK 后按练度排序、灰显未持有
#持有率                深渊样本里各角色持有比例
```

`#全部深渊` 只有原神这一个：星铁同名功能必须带 `*`（`*全部深渊` / `*深渊总览` / `*深渊汇总`）。

幻想角色数据来自 [Alioth.wiki](https://alioth.wiki/)，按指定月份查询，未收录月份直接提示暂无数据。
角色资料沿用喵喵数据；绑定 CK 后按持有角色、限制元素/特邀名单及等级 ≥70 筛选，开幕试用角色按 80 级补入；未读取到 CK 时展示全部可用角色。

**剧诗主题**：锅巴面板 → 小火花 → 原神查询 →「幻想角色 / 小剧诗主题」，可选浅色、深色或跟随全部深渊，两张图共用。默认跟随全部深渊；全部深渊设为浅色时，幻想角色也使用浅色。

**随机风景背景**：内置 50 张原神观景点原图，统一平铺在 `resources/bg/`。锅巴面板 → 小火花 → 原神查询，将「深渊/剧诗/配队背景」填为 `plugins/xhh-TL/resources/bg`，即可每次随机使用风景图；也可指定其中一张图片。体力立绘卡改用自动取色，不再使用独立底图，旧 `tl_portrait_bg` 配置不再生效。

| 配置项 | 作用 | 默认值 |
| --- | --- | --- |
| `role_combat_bg_folder` | 深渊、剧诗、配队等背景；支持单图及多层分类目录 | `plugins/xhh-TL/resources/bg/bg1.png` |
| `role_combat_theme` | 幻想角色与小剧诗主题；`light` 浅色、`dark` 深色，留空跟随全部深渊 | 空 |

内置目录保留 `bg1.png`、`bg2.png` 供单图指定和兜底，随机背景只抽 50 张风景。自定义图库仍支持分类子目录，角色立绘仍按原有角色名筛选；旧版内置背景路径自动兼容。素材来源记录见 [观景点来源](resources/bg/来源.json)。

配队与持有率数据源是[提瓦特小助手](https://api.yshelper.com)，无 CK 也能出通用榜。

直接把**游戏内抽卡链接**发过来也行——那条路能拿到完整逐抽记录，默认增量、加「全量」可强拉，
拉完同样直接出总览图。

- 走 stoken 换 `e_hkrpg_token`，**不需要抽卡链接、也不需要 authkey**
- 常驻池（群星跃迁）走 `GachaType_Standard`，和其它池一样能免链接更新
- 小程序接口只给五星和垫抽数。为了让总抽数与保底成立，五星之间用三星占位补足
  （每次更新重建，所以幂等）；代价是「未出四星」偏大，四星统计得靠链接或导入
- **普通更新 / 导入**保留旧记录，按「item_id + id 前 10 位时间戳」判重，反复更新不会重复计数
- **强制更新会删除当前 UID 已导入的三星、四星及官方窗口外的历史记录**，其他 UID 不受影响。
  官方来源只提供五星与垫抽，重建后可再导入小助手文件或工坊历史；任一卡池未拉齐都保留原记录
- 单个卡池拉取失败不影响其它池，失败的池会跳过，下次更新自动补上
- 导入支持 SRGF v1.0 / UIGF v4.x / UIGF v2.x / 星铁小助手 JSON / Excel `.xlsx` / csv，认不出结构时会兜底
  在 JSON 里找带 `gacha_type` 的记录数组
- 小助手文件：在「星铁小助手」小程序点 **同步云端 → 导出 JSON**，私聊发送 `*导入小助手记录` 后上传文件。
  四个导出数组全部导入，联动记录按每条的卡池类型分开，反复导入不重复计数
- 文件导入指令后可加 `json` / `excel` / `xlsx`，也可直接接文件下载链接。群里使用
  `*强制导入记录` / `*强制导入抽卡记录` / `*强制导入小助手记录` / `*强制导入小助手抽卡记录`；
  这里的「强制」只允许群内导入，**不清空旧记录**
- 工坊导入只查询本人已绑定的 UID，补历史五星与 UP 标记；不拿旧云端垫抽覆盖新进度。
  未找到记录时，先在「星穹工坊」小程序同步云端记录，再发 `*导入工坊记录`。
  工坊提供四星总数但没有四星逐抽明细，四星仍以文件或游戏链接为准；工坊 rd_card_* 对应联动角色 / 光锥池（21 / 22），计入总览且分池计算保底
- 这几条指令的优先级压在 genshin / xiaoyao-cvs 之前，避免被抢；原神的抽卡链接照旧交回 genshin

## 安装

在**云崽根目录**执行。三个源任选一个（内容完全一样，推荐国内的 gitcode 或 gitee）：

**gitcode（国内直连最快）**
```bash
git clone --depth=1 --single-branch https://gitcode.com/ccxhan/xhh-TL.git ./plugins/xhh-TL
```

**gitee（国内）**
```bash
git clone --depth=1 --single-branch https://gitee.com/longhengmu/xhh-TL.git ./plugins/xhh-TL
```

**GitHub**
```bash
git clone --depth=1 --single-branch https://github.com/cchanlan/xhh-TL.git ./plugins/xhh-TL
```

装依赖：

```bash
pnpm install --filter=xhh-TL
# 没用 pnpm 的话：npm install --no-save --prefix ./plugins/xhh-TL
```

重启生效。首次启动会从 `config/default_config.yaml` 生成 `config/config.yaml`。

**必需**：`miao-plugin`（角色数据与渲染框架）。
**可选**：`genshin`（没有则自动走内置兼容层）、`Guoba-Plugin`（图形化配置）、
gsuid_core + 鸣潮插件（鸣潮体力）、Node ≥ 22.5（鸣潮读库更省事）。

### 输出图片类型

锅巴面板 → 小火花 → 基础设置 →「输出图片类型」，或改 `img_type`。插件所有出图指令
（体力卡 / 立绘卡 / 桌面小组件 / 全部深渊 / 抽卡记录 / 帮助面板…）统一用它，改完下次出图生效。

| 取值 | 说明 |
| --- | --- |
| `jpeg` | 默认。体积小、全平台通用 |
| `png` | 无损，体积最大 |
| `webp` | 体积最小。⚠️ 微信（ComWeChat）适配器不认，会把图降级成「文件」发出去；QQ / OneBot 正常 |

选 `jpeg` 时，质变仪 / 洞天宝钱到期提醒卡的圆角会自动改成直角 ——
JPEG 装不下透明通道，硬裁会让四角变黑。

## 模块开关

每个功能模块都有独立开关，**关掉后该模块的指令一律不再响应**，
`#小火花帮助` 里对应的条目也随之消失；某个板块的条目全被关掉时整块不再渲染。
业务开关默认值沿用旧版，但**新用户安装列表为空**，开关不会安装任何模块。老用户迁移保留原开关。

在锅巴面板（`http://<你的IP>:2536/guoba/#/plugin/@/xhh-TL`）勾选，或直接改 `config/config.yaml`：

| `gs_all_abyss` | 开 | `#全部深渊` 停用 |

## 数据与隐私

凭证只从本机既有来源读取（云崽绑定库、`xiaoyao-cvs-plugin` 等的 stoken yaml、gsuid_core 的
`GsData.db` 只读借用），插件自己不落盘任何账号密码，也不外传。抽卡记录写进云崽的

## 独立扩展页面

支持扩展协议的锅巴会自动发现插件 `guoba/` 目录，在左侧 **扩展页面 → 小火花模块中心** 显示卡片页，无需手动新建页面。支持搜索、安装状态筛选、功能/素材分类、操作确认及后台状态自动更新。安装和卸载仍在重启后生效。

参数设置通过页面右上角“插件设置”进入。没有扩展页能力的锅巴继续使用原插件配置页中的模块管理兼容入口。

### 鸣潮模块依赖

安装“鸣潮体力”会自动安装“体力查询”及 SQLite 兼容依赖。要卸载体力查询，请先卸载依赖它的鸣潮体力模块。

### 安装状态与帮助同步

- 安装/卸载处于“待重启”时，帮助图和文字帮助仍展示当前进程可用的功能；重启应用后再增删，重新安装后恢复。
- 未安装、已关闭或加载失败的功能不列出业务帮助。启动时关闭的功能重新开启后，需要重启才加入帮助；其他已经加载的功能仍保留原开关行为。
- 鸣潮未安装或未启用时，体力查询/推送条目不列鸣潮指令；鸣潮安装后仍需在插件设置中启用其开关。

- 过码部署归在“管理·其它”，卸载签到后不会留下误导性的签到分组。
- 星铁全部深渊需要 miao-plugin；缺少该依赖时不加载成绩指令，也不将其列入帮助。

## 发布与升级保护

模块版 2.1.0 使用 coreApi=2，模块目录声明最低核心 2.1.0、Node 18.17.0。旧核心会拒绝此目录，请先更新核心再安装或更新模块。缓存目录不兼容时使用内置目录，不能让未来模块版本把管理入口一起拖垮。

安装核心时执行 `pnpm install --dir plugins/xhh-TL`。核心声明模块共用的 JS 依赖，不再依赖宿主恰好安装相同库；sharp 为可选依赖，缺失时普通渲染降级，需要 sharp 的版本资料模块会报告依赖错误。鸣潮读库仍需可用 SQLite 驱动（Node 内置或宿主已安装的兼容驱动）。

升级预下载会检查同名模块文件；与已知旧版原件或将安装内容都不一致时停止，请先备份处理自定义文件，不自动覆盖。原用户配置、记录与额外自备素材不属于卸载目标。

同一用户的单目的地订阅不能被另一个机器人覆盖或取消。需要迁移订阅时，在原机器人处关闭后再到目标机器人开启。取消或重新设置订阅后，尚未发送的旧汇总/推送会再次核对订阅；已发出的官方签到/兑换请求和已经送达的平台消息无法撤销。

模块重载会取消旧 cron job，并阻止旧代回调继续发送。当前任务未退出时新代相同任务不并行执行；重启生效的安装/卸载语义不变。

### 下载代理

| 配置项 | 用途 | 默认 |
| --- | --- | --- |
| `download_proxy` | 模块下载使用的 HTTP/HTTPS 代理地址 | 空；使用 `HTTPS_PROXY` 环境变量或直连 |

下载较慢时，在锅巴插件配置的模块管理入口填写“模块下载代理”并保存，再安装模块。下载总时限为10分钟，连接30秒没有数据会中止；失败不会写入半成品安装状态。代理仅用于公开模块文件，不发送游戏账号凭据。
