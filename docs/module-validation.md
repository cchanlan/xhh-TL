1. 旧核心可接受依赖新核心工具的模块目录：新增最低核心/Node 检查并将 coreApi 升为2；旧 coreApi=1 的真实校验器拒绝新目录。核心版本2.1.0，Node最低18.17.0，构建版本包含契约字段。
2. Windows 大小写不敏感路径可绕过核心文件保护：原基线实际接受 utils/ModuleManager.js 与 resources/HELP/help.html；现在按小写保护，补充保留标识、路径文件/目录冲突与总大小检查。
3. 首次迁移会覆盖现有自定义代码/模板：使用旧跟踪文件哈希基线，只允许原件或与新内容相同的文件；自定义文件与链接目标拒绝覆盖。预下载脚本也检查正式目录，已有冲突缓存不覆盖。
4. 同用户跨机器人关闭/开启订阅可能删除或覆盖其他机器人记录：新增所有者检查及订阅revision，不扩展为多目的地功能。
5. 签到/米游币汇总、体力推送、到期提醒等待接口/渲染期间取消订阅仍可能发旧消息；发送前重读订阅，已取消/变更则放弃。体力轮询armed写回检查原订阅版本，不覆盖新订阅。
6. 模块重载可能留下旧cron回调，后台任务重叠：新任务代际管理取消旧job，跨代互斥未结束任务，旧事件钩子拒绝继续处理；投递前检查任务代际。
7. 核心依赖只声明 moment/yaml，业务依赖恰好借用宿主：补齐 lodash/md5/node-fetch，并声明可选sharp；隔离副本 npm install --ignore-scripts 后解析全部声明依赖均来自自身 node_modules。
8. 安装状态仅逐模块验证而不验证整组键、依赖和归属：校验完整installed/pending集合；首次状态用wx排他创建。未恢复完的事务不再加载可能混合版本的业务。
9. API增加显式登录头、同源Origin/Sec-Fetch-Site与JSON写请求限制；真实锅巴鉴权继续负责强令牌验证，防止把插件内存在令牌头当成身份校验。
